# Olist E-Commerce Analytics

## Project Overview

This project simulates an end-to-end data analytics engagement for a fictional multinational e-commerce marketplace called Olist.

The objective is to analyze sales performance, customer behavior, product performance, payment patterns, and delivery operations to generate actionable business insights.

## Business Objectives

- Analyze sales and order trends.
- Identify top-performing product categories.
- Analyze customer purchasing patterns.
- Evaluate delivery performance.
- Investigate customer satisfaction.
- Develop a business intelligence dashboard.
- Provide data-driven recommendations to management.

## Dataset

Source: Brazilian E-Commerce Public Dataset by Olist.

Dataset link: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
